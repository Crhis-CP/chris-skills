# 同一事件多篇报道：选哪篇当代表

**原文**：`source/representative.ts` 中的 `pickRepresentative`（代码，逐字节复制）。依据：Owner 2026-11-08“同一件事分数明显更高，可以优先当代表”（TASK-0591）。

## 规则

1. 找出这一组报道里的最高分。
2. **比最高分低 3 分及以上的先出局**（按百分位整数比较，66.1 − 63.1 算 3 分，不算 2.9999）。
3. 剩下的按下列顺序排，第一名当代表：
   1. 代表优先级，数字小的在前：
      - 0：信源等级 T1；
      - 1：发布者正是这件事的当事公司（信源归属的公司就是事实主体），且以机构身份发布；
      - 2：同上，但以个人身份发布；
      - 3：其他（包括无法核实的）；
   2. 有全文的优先；
   3. 分数高的优先；
   4. 出现时间早的优先；
   5. 最后按条目 ID 字母序，保证结果稳定。

## 说明

- “同一事件”由归组步骤判断（仓库另有 `group-*.md` 一组提示词，按事实标题、主体、动作、对象、日期归组），这次没有提取；需要的话可以补。
- 这条规则只影响以后重新结算的事件，不回补旧的代表稿。
