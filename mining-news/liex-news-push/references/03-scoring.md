# 打分：四个维度、总分、门槛

只给通过了范围判断和七项核验的事项打分。分数显示在卡片上，让读者一眼看出重要程度。

## 一、四个维度（各 0–10 分，可以有一位小数）

### 传导 `link`：离 LIEX 的经营有多近（权重 4）

| 分 | 情况 |
|---|---|
| 9–10 | 点名 LIEX 或 3Q 项目；或者规则直接适用于 LIEX，比如卡塔马卡省的锂矿政策、冰川法的修改 |
| 7–8 | 直接适用于阿根廷锂矿或矿业企业的国家规则；卡塔马卡省影响矿业的税收、能源、道路、用水；通往项目的道路和口岸受阻 |
| 5–6 | 对所有企业都适用、矿业也明确受影响的规则，比如外汇、劳动、进出口；同行企业在 RIGI 等同一制度下的结果（先例参考） |
| 3–4 | 有传导路径，但要经过好几步才到 LIEX |
| 0–2 | 几乎说不出传导路径，这种情况本应在范围判断时被排除 |

### 变化 `change`：变了多少，走到了哪个阶段（权重 3）

| 分 | 情况 |
|---|---|
| 9–10 | 已经生效、会直接改变成本、许可或经营方式的规定；已经发生、规模很大的事件 |
| 7–8 | 立法通过、正式公布；RIGI 批准；法院裁定暂停某项规定；交易签约 |
| 5–6 | 法案进入关键阶段，如委员会意见、一院通过；RIGI 申报；实施细则的征求意见稿 |
| 3–4 | 法案刚提交；有正式文件，但改动很小 |
| 0–2 | 只有表态、意向，没有正式文件 |

### 新增 `new`：带来了多少读者还不知道的事实（权重 2）

| 分 | 情况 |
|---|---|
| 8–10 | 第一次出现的事件，或者阶段发生了变化，有新的编号、日期、金额、条件 |
| 5–7 | 已知事件的重要细节第一次公开 |
| 0–4 | 主要是复述旧事实（这种多半会在“对照已推送”一步就被丢弃） |

### 时效 `time`：多快需要知道（权重 1）

| 分 | 情况 |
|---|---|
| 8–10 | 正在发生，或者 30 天内生效、截止，比如道路封锁、即将生效的新规定、申报截止日 |
| 4–7 | 3 个月内会落地 |
| 0–3 | 没有明确时间，或者时间在很久以后 |

## 二、总分

```
总分 = 4 × link + 3 × change + 2 × new + 1 × time
```

权重之和是 10，所以总分在 0–100 之间，保留整数。

先单独判断每个维度，再代入公式计算。不要先想好总分再倒推各维度，也不要为了过门槛调整某个维度。

## 三、封顶

| 情况 | 总分上限 |
|---|---|
| 只有官员表态，还没有正式文件、正式提案或已经发生的动作 | 64 |
| 同一事件的报道，只是比已推送的卡片多了一点细节，阶段没变 | 59（即不推） |

两个上限都适用时，取较低的。

## 四、门槛和分档

**总分 60 分及以上的才推。** 推送的都标“精选”，卡片上显示分数和分档：

| 总分 | 分档 | 含义 |
|---|---|---|
| 85–100 | 重大 | 直接改变 LIEX 的经营规则或条件，或者是罕见的重大事件 |
| 70–84 | 重要 | 明确影响 LIEX 经营环境，值得当天看 |
| 60–69 | 关注 | 有传导路径，读者应该知道 |
| 0–59 | 不推 | |

不设每次或每天的条数下限。没有达到 60 分的，宁可不推。
