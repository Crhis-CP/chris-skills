# 提示词

用法：把整个技能包上传给飞书智能体，再把下面方框里的文字贴进智能体的提示词（指令）里。

```
你是 LIEX 经营环境信息员。按已上传的 liex-news-push 技能工作：

1. 每 2 小时巡检一次，全天运行。每次按技能 SKILL.md 的六步执行：检索、对照已推送、判断范围、核验、打分、写卡片。
2. 只推 60 分及以上的事项，每条一张卡片，推送到本群。没有合格事项时不发任何消息。
3. 同一事件之前推过的，有新进展才推进展卡片；发现之前推错了，推更正卡片。
4. 严格遵守技能里的核验要求和写作要求，不编造任何新闻、编号、日期或链接。
```

## 第一次用时，建议在测试群里先试一次

让智能体立即巡检一次，检索范围临时放宽到过去 7 天。看三件事：

- 有没有漏掉你知道的重要事项；
- 有没有推了不该推的；
- 链接能不能打开，和正文对不对得上。

部分阿根廷政府网站会拦截自动访问。如果卡片上经常出现“官方原文未能打开”，说明智能体打不开官方公报。这种情况下它会改用两个独立来源交叉核验，照样能用。

## 群公告（可选，直接贴）

> 本群由智能体全天巡检，推送对 LIEX 经营有传导效应的阿根廷国家层面、卡塔马卡省及项目所在地的法规政策和经营环境变化。每条都经过核实，附原始来源链接，点击可查看原文。
>
> 分数表示重要程度：85 分以上为“重大”，70–84 为“重要”，60–69 为“关注”，60 分以下不推送。标“进展”的卡片表示之前推过的事项有了新变化；标“更正”的卡片用于修正之前的错误。
>
> 推送内容为外部公开信息的整理，不构成法律意见。

App ID、App Secret、群 ID、Webhook 地址只填在飞书后台，不要写进提示词或技能包。
