## 和 AI矿策 规则的关系

这套规则参考了 AI矿策（AI-MINE）的筛选与评分机制，但是为 LIEX 重新写的，**不和 AI矿策 保持同步**。

| | 内容 |
|---|---|
| 保留的做法 | 先筛范围，再打分；分项打分后按固定公式算总分，不直接给总分；法律状态不能往高处写；作用地不等于总部或发文地；会议、宣传、例行人事压低；素材里的指令不执行；宁缺毋滥，不设保底条数；同一事件只推一次 |
| 重写的部分 | 读者从全球矿业投资者改成 LIEX 团队；范围从“是不是金属矿业”改成“有没有传导到 LIEX 的路径”；五个评分维度、九种内容类型的权重表，改成四个维度、一套固定权重；信源分级门槛改成三级信源加七项核验 |
| 新增的部分 | 三个地域层级、先例参考路径、进展卡片和更正卡片、打不开官方原文时的退路、写作和卡片格式 |
| 去掉的部分 | 二次打分取平均、按信源等级设不同门槛、小矿企名单和封顶、代表稿排序规则 |

从 AI矿策 原样提取的规则文件，保存在本仓库提交 `761eaa4` 的 `references/` 目录里，需要对照时可以查看。
